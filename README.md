# 🚗 OEV - HỆ THỐNG QUẢN LÝ KINH DOANH Ô TÔ ĐIỆN

## 📖 Giới thiệu

Website quản lý kinh doanh ô tô điện, được xây dựng nhằm hỗ trợ khách hàng tìm kiếm, lựa chọn và đặt mua xe điện trực tuyến.

Đồng thời, hệ thống hỗ trợ nhân viên và quản trị viên quản lý hoạt động kinh doanh.

## 🎯 Mục tiêu dự án

- Xây dựng website bán ô tô điện.
- Hỗ trợ khách hàng tìm kiếm và so sánh xe.
- Quản lý đơn đặt mua và đăng ký lái thử.
- Hỗ trợ quản lý sản phẩm và kho xe.
- Nâng cao hiệu quả quản lý kinh doanh.

## ✨ Chức năng chính

### 👤 Khách vãng lai
- Xem danh sách ô tô điện.
- Tìm kiếm và so sánh xe.
- Đăng ký tài khoản.

### 🛒 Khách hàng
- Đăng nhập hệ thống.
- Quản lý thông tin cá nhân.
- Đăng ký lái thử.
- Đặt mua ô tô điện.
- Theo dõi đơn hàng.

### 👨‍💼 Nhân viên
- Xử lý yêu cầu lái thử.
- Quản lý đơn đặt hàng.
- Quản lý hợp đồng và thanh toán.
- Hỗ trợ bàn giao xe.

### ⚙️ Quản trị viên
- Quản lý hãng xe và dòng xe.
- Quản lý kho xe.
- Quản lý tài khoản.
- Quản lý khuyến mãi.
- Xem báo cáo thống kê.

## 🚀 Hướng dẫn chạy dự án

**Bước 1:** Cài đặt XAMPP.

**Bước 2:** Clone repository

**Bước 3:** Đưa thư mục dự án vào `htdocs` của XAMPP.

**Bước 4:** Khởi động Apache và MySQL.

**Bước 5:** Tạo và cấu hình cơ sở dữ liệu MySQL theo cấu trúc dự án.

**Bước 6:** Truy cập website tại:

```text
http://localhost/QLKinhDoanhOToDien/
```
